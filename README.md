# 風起群島 V5.1｜像素即時策略對戰

依 V5.1 企劃重製的網頁 RTS 原型。戰場使用 16 位元風格的 Q 版角色、建築與資源圖集。村民會依資源拿出斧頭、十字鎬或採集籃，並用木槌施工。戰鬥動畫包含各兵種攻擊、受擊、倒地和遠程彈道，戰場與效果由 Canvas 繪製。帳號和戰績使用 MySQL。

## 啟動

1. 在此資料夾開啟終端機。
2. 執行 `npm install` 安裝 MySQL 連線套件。
3. 執行 `node server.js`。
4. 瀏覽器開啟 `http://localhost:8080`。

若要兩人同一台電腦對戰，開兩個瀏覽器分頁：第一位建立房間，第二位輸入房間碼加入。區域網路對戰時，兩人都連到主機的區域網路網址與連接埠 `8080`。也可以選「對戰 AI 守軍」進行單機練習。伺服器會優先使用託管平台提供的 `PORT` 環境變數。

## 網路部署（Render）

根目錄的 `render.yaml` 可用來建立 Render Blueprint，設定 Node.js Web Service、`npm start` 啟動指令、`/healthz` 健康檢查與單一 instance。部署完成後，分享 Render 網址及遊戲房間碼即可邀請好友。頁面會依網址自動使用安全 WebSocket 連線。

目前房間與戰局存在單一 Node.js 程序記憶體中；服務重啟或重新部署時進行中的房間會消失。免費服務長時間閒置後會休眠，喚醒時首次載入可能較慢；瀏覽器會自動重連並嘗試恢復尚存的房間。

## MySQL 帳號與歷史戰績

在 Render 的 Environment 中設定 `MYSQL_HOST`、`MYSQL_PORT`（預設 3306）、`MYSQL_DATABASE`、`MYSQL_USER`、`MYSQL_PASSWORD`。資料庫需允許 Render 主機連線，帳號需有該資料庫的建表、查詢、寫入與刪除權限。資料庫要求 TLS 時設 `MYSQL_SSL=true`，私人 CA 可透過 `MYSQL_SSL_CA` 設定 PEM 憑證。TLS 會驗證伺服器憑證。

首次連線會自動建立 `game_accounts`、`game_sessions`、`game_matches`、`game_match_players` 四張表。密碼以 scrypt 加鹽雜湊，登入使用 HttpOnly、SameSite cookie，HTTPS 下加上 Secure。註冊後自動登入，訪客可以繼續遊玩。

在登入狀態開始的對局會在主堡摧毀時記錄勝敗、對手、模式、時間與時長。歷史頁顯示最近 50 場和累積勝敗。戰績以伺服器結果為準，資料庫交易與對局 ID 避免重複記錄。離線或尚未結束的對局不會計入。資料庫短暫中斷時，執行中的服務會重試保存，若服務在保存前重啟，該筆待存戰績可能遺失。

遊戲大廳有入場、背景海風和候戰動畫，結算依勝利、戰敗或平手播放不同演出。系統設定減少動態效果時會停用這些動畫。

## 操作

- 左鍵選取人物，再左鍵點空地移動、點資源採集、點敵方目標攻擊。左鍵點另一位人物可切換選取，Shift 可加選，拖曳可框選。要點地建造可按「取消選取」或 Esc。
- 右鍵空地移動，右鍵資源格讓選取的村民採集，右鍵可見的敵軍或敵方建築會讓戰鬥單位攻擊。觸控可按「下達指令」再點目標。
- 按 X 可指定攻擊，目標為敵方單位或建築。按 Z 停止部隊，Esc 或右鍵可取消正在指定的指令並保留部隊選取。
- 右下角的「招募部隊」可直接選主堡或兵營。主堡訓練村民。要招募士兵，先在面板按「建造兵營」，再點視野內的空地。完工後同一面板可選兵種並查看倒數。新兵會出現在建築旁，出口被堵住時請移開單位。
- 滑鼠移到兵營可看耐久、施工進度或目前訓練項目。右鍵自己的主堡或兵營可直接開啟該建築的招募面板。
- 選取村民後也可選建築，再點視野內的空地放置。採集站只能蓋在木材、石材或金礦格，村民會站在工地旁施工。
- 也可以先點視野內的土地，再從指揮面板選建築。遊戲會優先派遣可到場的待命村民，其次派採集中的村民。將滑鼠移到建築上可查看耐久和施工等狀態。
- 滾輪縮放；中鍵拖曳；WASD 或方向鍵平移。單位會繞過建築，不能穿牆。
- 在視野內的空地建造相連的城牆，留一格放城門。城門完工時預設關閉，點選自家城門即可手動開關。開門後雙方都能通過，右鍵自家城門可直接開關。門下有單位時會等待通過後自動關閉，也可以取消等待。
- 主動攻擊會在視野內自動交戰；堅守不追擊；強制移動會忽略沿途敵軍。攻擊會在單位射程內停止移動並依攻擊間隔結算。

施工時間已縮短為兵營和防禦塔 6 秒、農場和採集站 4 秒、城門 3 秒、城牆 2 秒。村民走到工地的路程另外計算。

## 目前包含

40×40 鏡像資源地圖、四種資源、村民採集與施工、五種單位、七種建築（含城牆與可開關城門）、施工圖集、三種樹木、岩石、金礦和果叢、連續座標移動、建築碰撞、建築耐久、射程攻擊、戰爭迷霧、記憶地圖、伺服器權威房間同步、AI 練習房與主基地摧毀勝利條件。AI 練習有 75 秒準備時間，期間 AI 會在家發展，仍會反擊靠近的敵軍。

伺服器只向每位玩家傳送其可見敵情。對戰數值、路徑尋找與 AI 仍屬原型，尚未完成多輪平衡與壓力測試。
