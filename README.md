# 界域爭鋒 V5.1｜像素即時領土戰

依 V5.1 企劃重製的網頁 RTS 原型。畫面以 Canvas 程式繪製像素地形、建築與兵種徽章，不依賴外部美術素材或 npm 套件。

## 啟動

1. 在此資料夾開啟終端機。
2. 執行 `node server.js`。
3. 瀏覽器開啟 `http://localhost:8080`。

若要兩人同一台電腦對戰，開兩個瀏覽器分頁：第一位建立房間，第二位輸入房間碼加入。區域網路對戰時，兩人都連到主機的區域網路網址與連接埠 `8080`。也可以選「對戰 AI 守軍」進行單機練習。伺服器會優先使用託管平台提供的 `PORT` 環境變數。

## 網路部署（Render）

根目錄的 `render.yaml` 可用來建立 Render Blueprint，設定 Node.js Web Service、`npm start` 啟動指令、`/healthz` 健康檢查與單一 instance。部署完成後，分享 Render 網址及遊戲房間碼即可邀請好友。頁面會依網址自動使用安全 WebSocket 連線。

目前房間與戰局存在單一 Node.js 程序記憶體中；服務重啟或重新部署時進行中的房間會消失。免費服務長時間閒置後會休眠，喚醒時首次載入可能較慢；瀏覽器會自動重連並嘗試恢復尚存的房間。

## 操作

- 左鍵點選單位；Shift 加選；雙擊一種兵可選取畫面內同類部隊；拖曳框選。
- 右鍵移動。選取全村民後右鍵資源格可採集，採得資源直接進入庫存。
- 按「指定攻擊」後右鍵敵軍、敵方建築或與我方土地相鄰的敵方土地。攻佔土地需先打掉土地耐久；敵方建築必須先被摧毀。
- 選取村民後選建築，再點我方空地放置；採集站只能蓋在木材、石材或金礦格。選取主基地或兵營後可生產單位。
- 滾輪縮放；中鍵拖曳；WASD 或方向鍵平移。單位會繞過建築，不能穿牆。
- 主動攻擊會在視野內自動交戰；堅守不追擊；強制移動會忽略沿途敵軍。攻擊會在單位射程內停止移動並依攻擊間隔結算。

## 目前包含

24×24 鏡像公平資源地圖、四種資源、村民採集與施工、兵營與防禦塔、劍士／弓箭手／長槍兵／攻城車、連續座標移動、建築碰撞、土地與建築獨立耐久、射程攻擊、戰爭迷霧、記憶地圖、伺服器權威房間同步、AI 練習房與主基地摧毀勝利條件。

伺服器只向每位玩家傳送其可見敵情。對戰數值、路徑尋找與 AI 仍屬原型，尚未完成多輪平衡與壓力測試。
